# Known limitations

English | [繁體中文](known-limitations.zh-TW.md)

Back to the [README](../README.md).

None of the issues below cause invalid credentials to be sent repeatedly. Items 1–28 are all low impact (they need specific timing or uncommon conditions to happen, or only affect display) and are sorted from highest to lowest impact. Items 29–46 are appended at the end and not sorted with the earlier items; their impact rating is at the end of each item's "What happens" column. Items marked "not tested" were inferred from the code and not actually reproduced; "speculative" means it hasn't even been confirmed whether it happens; "observed once (n=1)" means it was seen only once.

Test coverage: the app is tested on Windows 11 x64. Running it with standard (non-elevated) rights hasn't been tested; by design the exe itself doesn't need administrator rights, though installing the .NET runtime may need them (see [System requirements](../README.md#system-requirements) in the README).
